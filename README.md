# ServiceFlow

ServiceFlow is a multi-tenant SaaS business management platform
for service-based companies.

## Planned Features

- Business registration
- Authentication and authorization
- Customer management
- Employee management
- Service management
- Booking management
- Dashboard and reporting
- Invoice management
- Email notifications

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- C#
- ASP.NET Core
- .NET 10

### Database
- PostgreSQL
- Entity Framework Core

### Testing
- xUnit
- Moq

### DevOps
- Git
- GitHub
- GitHub Actions
- Docker
